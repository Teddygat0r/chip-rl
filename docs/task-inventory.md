# Current local task inventory

This checkpoint exposes **33 distinct families: 6 pilots and 27 experimental tasks**. This is a source/API inventory, not a fresh 33-family simulation or physical qualification. The [prior published 25-family checkpoint](https://github.com/Teddygat0r/chip-rl/tree/codex/verified-25-family-checkpoint) is separate. Paths to evidence below refer only to files present in this snapshot; earlier v33/v35/v37 claims remain version-scoped in [current status](current-status.md).

Every row names one public reset/step environment and its JSON-lines module. Named-task constructors take the row’s family name: `ChipEnv(name)`, `CycleEnv(name)`, `ExpansionEnv(name)` and `MemoryEnv(name)`. The newer block families, BF16, Hadamard and integer RMS take `n=4` by default; fused takes `k=4`, sparse24 takes `g=4`, and CDC takes no required arguments. After `reset(seed=1)`, all but CDC use `step({"rtl": source})`; CDC uses `step({"architecture": "binary_gray", "sync_stages": 2})`. Baselines are reference source choices, not extra families. Follow the [contract](../chip_rl/contracts.md) and family-specific code before an episode.

## What the evidence proves

The recent integer RMS, block RLE, block FOR, BF16 and Hadamard results document separate frozen-reference, finite five-N development/heldout RTL and mapped evaluations. Their fixed hard gates determine whether a correct source is reward-qualified; a qualified candidate may still earn zero proxy reward. The [post-Hadamard source unit run](../evidence/hadamard-int8-v1/integration-verification.json) passed 240/240, with cache-only installed-wheel direct and JSONL API smokes. This is not a fresh 33-family public-API RTL/mapped sweep. BF16 host arithmetic exhaustiveness does not imply exhaustive RTL. Both BF16 references qualified but scored zero in finite RTL/mapped runs. Hadamard serial qualifies at zero; its stage-parallel reference is correct but unqualified solely due to N=16 area above 4× baseline. There is no completed physical integer RMS result, routed PPA for this suite, or learned-agent gain claim.

The [`quality` API](../chip_rl/quality/env.py) changes scoring profiles for dot, tensor and TLB; it does not add families. The [`history` checks](../chip_rl/history/evaluate.py) are CRC and retirement verification utilities. `serial_comb_root` and `serial_shiftpack` are reference variants of integer RMS and block FOR respectively. Prospective work is excluded until integrated into a public environment.

For parsers and automated checks, use the [JSON inventory](../evidence/current-inventory.json). It includes each family once, entry-point modules, baselines, available evidence, historical evidence references and explicit exclusions.
