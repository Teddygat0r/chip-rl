The agent supplies only module candidate with parameters ROWS,COLS,BANKS and fixed ports row[5:0],col[5:0],addr[9:0]. It is a pure stateless combinational function for valid row<ROWS and col<COLS. Every logical tile word must map bijectively to exactly ROWS*COLS physical words, without padding. Physical bank=addr%BANKS, bank slot=addr/BANKS. Out-of-domain row/col behavior is unspecified. Port, state, hierarchy, directives and resource changes are rejected. All in-domain mappings are exhaustively checked in RTL and synthesized logic, including reversed visitation. No clock, request type, lane ID, mask or data is available to the mapper.

The trusted clocked engine instantiates one identical mapper per lane, captures a masked warp of reads or writes, and services one 32-bit word per bank per cycle. It cannot accept another warp until the response is consumed. Each bank chooses its oldest pending lane. Identical-address reads broadcast; writes, including repeated addresses, serialize in lane order. Masked lanes return zero, stores return zero, and all reads return the previously stored logical value. An empty mask still produces a response after one service cycle. Reset clears engine state and memory; candidate mapping is stateless. Address/data changes after capture must not affect pending work. Responses remain stable during output backpressure. Every response is checked; duplicates, drops and outstanding work at termination fail. Capacity, ports, engine and workload are immutable.

Initial tile-fill stores, mixed accesses, persistent overwrites, readback and masks are scored. Per-request service cycles are measured from capture to response production in HDL, excluding consumer stalls, and must match the independent host bank-occupancy model. Wall cycles and output stalls are separately reported. There is no routed-frequency claim. Generic mapped cells/depth measure only one mapper, not SRAM, bank engine, replicated total area, physical area or power.

Transpose objective mixes rows and columns heavily; diagonal objective emphasizes diagonal accesses but retains rows, columns, random access and broadcasts. These two fixed distributions cannot be selected by candidate action. Reward requires complete correctness, <=64 mapper cells, <=12 mapped logic levels and total service cycles <=2x row-major for every structural case. For eligible designs reward=clamp(geomean(baseline_service/candidate_service)/(1+mean_mapper_cells/64),0,4). Row-major is exactly1 despite its zero-cell wiring implementation; no fake area floor or memory-area constant is introduced. This explicitly priced mapper-overhead objective is a research preference, not PPA or estimated GPU speedup.

Source-only reset/step API exposes development configurations. Heldout and reserve structural/workload splits and replay seeds are trusted-host options, never action fields. They are same-author qualification, not independent or guaranteed secret evaluation. A candidate may see only its observation/source; evaluator, engine, constraints, tools, journals and seeds require separate host ownership. Local tool limits are not a complete OS security sandbox.

Qualification also requires unscored directed masked-word overwrites with inactive-word preservation, ordered duplicate stores, empty writes, long-lived readback, zero reads immediately after reset before any refill, and reset cancellation while work is busy or a response is stalled. These checks never contribute cycles to reward. Partial writes here mean the declared per-lane 32-bit word mask, not unsupported byte write enables. Continuous assignments, always_comb and automatic wildcard event controls (always @* or always @(*)) are allowed; incomplete manual sensitivity lists remain forbidden.
