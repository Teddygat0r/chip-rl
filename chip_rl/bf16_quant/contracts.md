# Exact block BF16-to-INT8 quantization (bf16-quant-v1)

The candidate is a complete synthesizable Verilog/SystemVerilog module `candidate` with parameter N in {1,2,4,8,16}. Ports: clk, rst, in_valid, in_ready, in_data[511:0], out_valid, out_ready, out_data[255:0]. Rising-edge ready/valid handshakes accept one block and emit one ordered response. Active-high synchronous reset suppresses handshakes and cancels pending work. A blocked output remains asserted and stable. New blocks cannot inherit prior block state.

Lane i for 0<=i<N is raw BF16 bits in_data[16*i+:16]. Runtime k is signed five-bit in_data[260:256] (-16..15), and z is signed eight-bit in_data[268:261] (-128..127). All other input bits, including inactive lanes, are ignored. BF16 has sign bit 15, exponent bits 14..7, and fraction bits 6..0. A normal is (-1)^sign*(128+fraction)*2^(exponent-134); a subnormal is (-1)^sign*fraction*2^-133. BF16 format references: [RISC-V BF16 format](https://github.com/riscv/riscv-bfloat16/blob/main/doc/riscv-bfloat16-format.adoc), [Intel BF16 hardware numerics definition](https://www.intel.com/content/dam/develop/external/us/en/documents/bf16-hardware-numerics-definition-white-paper.pdf). The quantization and special-value behavior here are custom, not ISA conformance.

For finite x, y=clamp_INT8(round_ties_even(x*2^k)+z). Both signed zeros and values that round to zero produce z. Any NaN produces z regardless of sign/payload; +infinity produces 127 and -infinity produces -128 regardless of z. Every bit encoding is defined, with no exceptions or flags. Output bits [8*i+:8] hold y_i as signed two's-complement INT8. All inactive lanes and bits 128..255 are zero.

Evaluation compares an exact integer host oracle against source and Yosys-mapped Icarus simulations, including reset/backpressure, 257-cycle output stall, and reset while output is blocked. Per-request bound is 4*N+64 ready-high opportunities. Whole-run bound is requests*(4*N+64)+1 after last release. Area is generic Yosys/ABC cell count; completion is workload cycles. No model accuracy, FP ISA conformance, formal proof, physical PPA, or trained-RL claim is made.

All five N values must pass fixed gates: area<=4x serial, workload cycles<=serial, and saturated initiation interval<=N+6. Correct gate failure remains correct but unqualified. Only qualified cases receive balanced reward max(0,1-exp(mean(log(area_ratio*cycle_ratio))/2)). Gates and workloads are fixed before observing scored results.
