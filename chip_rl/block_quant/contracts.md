# Block-adaptive signed INT16 to INT8 (experimental proxy reward)

One request quantizes one block. The trusted host selects compile-time integer `N` from `1..16`. `candidate #(parameter N=4)` has `clk,rst,in_valid,in_ready,in_data[511:0],out_valid,out_ready,out_data[255:0]`. A candidate action supplies only complete synthesizable RTL. The active signed INT16 lanes are `in_data[16*i+:16]` for `0<=i<N`; the remaining lanes and bits256..511 are ignored.

Let `A=max(abs(x_i))` over active lanes, computing `abs(-32768)=32768` in at least 17 bits. Set `s=max(0,bit_length(A)-7)` with `bit_length(0)=0`. Thus `A=0,127` gives `s=0`, `A=128,255` gives `s=1`, `A=256` gives `s=2`, and `A=32768` gives `s=9`. For each active lane, divide the signed value by `2**s`, round to nearest with exact ties to even, then clamp to signed INT8 `[-128,127]`. `out_data[8*i+:8]` holds its two's-complement byte. Inactive byte lanes `i>=N` are zero; bits128..131 encode unsigned `s`; bits132..255 are zero. This exact integer algorithm defines the benchmark; it does not claim optimal quantization accuracy.

An input is accepted on a positive edge only if reset is low and `in_valid && in_ready`. Each accepted input produces exactly one in-order, registered output at least one later edge. A blocked output keeps `out_valid` and all 256 data bits stable. Synchronous active-high reset immediately suppresses ready/valid, and its active edge cancels all pending and blocked responses. The producer holds an offered request until accepted. Different valid architectures need not have the same latency.

The trusted host checks exact Python-integer oracle outputs, handshakes and progress on RTL and Yosys-mapped netlists. Unscored directed arithmetic probes cover extrema, every exponent transition, positive and negative ties, clamping, maxima at every lane, inactive lanes and ignored upper bits. Separate unscored protocol probes include a 257-cycle consumer stall, reset with blocked work, cancellation and recovery. The scored traffic run checks bursts and backpressure, ordered exact outputs, direct latency counters and a separate 32-request saturated stream. A pending accepted request may consume at most `2*N+64` ready-high service opportunities after acceptance, including its consuming cycle. Ready-low cycles do not age it. A whole-run watchdog permits `request_count*(2*N+64)+1` ready-high opportunities after the last release. Tool timeout, incomplete traffic, or RTL/mapped divergence rejects the candidate.

The response records generic Yosys/ABC cells, generic logic depth, workload completion cycles, saturated stream II, accepted-to-first-output and offered-to-consumption latencies, acceptance/consumption counts and backpressure counters, source and workload hashes. The fixed reward still scores `N={1,2,4,8,16}`; a requested N outside that set is additionally measured and paired against serial, without changing the five-point reward. Every measured N uses the same workload for candidate and fixed serial baseline. For each N, area ratio `rA=candidate cells / serial cells` must be `<=4`, workload completion ratio `rC=candidate cycles / serial cycles` must be `<=1`, and independently measured saturated stream II must be `<=2*N+3`. Equality at a gate passes. A verified candidate passing every scored gate receives `max(0,1-exp(mean(log(rA*rC))/2))`, equally weighting the five scored N values. The baseline qualifies at score 0. A correct design missing any scored hard gate remains `tested_correct=true` with its metrics and failed reasons visible, but `service_qualified=false`, `reward_qualified=false`, and reward 0. Invalid correctness, progress or baseline verification fails closed with zero reward. The area cap is fixed at four; the fully parallel N=16 reference exceeds it and remains unqualified.

These are synthesis and digital-simulation proxies, not routed area, clock frequency, power or silicon readiness. Formal and physical stages are not run. Source screening and tool timeouts do not provide OS isolation against a same-UID candidate with access to trusted files.
