# Exact block frame-of-reference (block-for-v1)

The candidate is a complete synthesizable Verilog/SystemVerilog module named `candidate`, with compile-time `parameter N=4`. Supported and scored N are exactly 1, 2, 4, 8, and 16. Ports: `clk`, `rst`, `in_valid`, `in_ready`, `in_data[511:0]`, `out_valid`, `out_ready`, `out_data[255:0]`. A transaction is accepted at a rising edge with `in_valid && in_ready`. Reset is synchronous active-high and suppresses both handshakes; it cancels pending work. Output remains asserted and data stable while blocked. Responses are ordered, one per accepted block, with no cross-block state.

For each block, bytes `x_i = in_data[8*i+:8]` for `0 <= i < N` are unsigned. Ignore all other input bits. Set `b=min(x_i)`, `r=max(x_i)-b`, and `w=bit_length(r)` (0 for r=0). Output bits 0..7 hold b, bits 8..11 hold w, then lane i's unsigned offset `x_i-b` occupies exactly w bits starting at `12+i*w`. With w=0 there are no offset bits. All remaining output bits are zero. Maximum occupied size is 140 bits. Output is canonical; widths or offsets that do not match the represented range are invalid.

Evaluation uses independent Python packing and decoding, source and Yosys-mapped Icarus replay, reset/backpressure checks, a 257-cycle output stall, and reset during blocked output. Per-request progress is bounded by `6*N+80` ready-high opportunities; the whole run has `requests*(6*N+80)+1` opportunities after the last release. Consumer stalls do not age service work. Area is generic Yosys/ABC cell count; completion is workload cycles. No timing, power, routing, model quality, or trained-RL claim is made.

Scoring requires correct source and mapped checks for exactly one case at each supported N. Fixed hard gates at each N are: area at most 4x serial, completion cycles at most serial, and saturated initiation interval at most `2*N+6`. A correct gate failure is unqualified with zero reward. Qualified reward is `max(0, 1-exp(mean(log(area_ratio*cycle_ratio))/2))`. The baseline is the frozen serial reference.
