# Exact signed INT8 Hadamard transform (hadamard-int8-v1)

The candidate is a complete synthesizable Verilog/SystemVerilog module `candidate` with parameter N in {1,2,4,8,16}. Ports: clk, rst, in_valid, in_ready, in_data[511:0], out_valid, out_ready, out_data[255:0]. Rising-edge ready/valid handshakes accept one block and emit one ordered response. Active-high synchronous reset suppresses handshakes and cancels pending work. A blocked output remains asserted and stable. New blocks cannot inherit prior block state.

Lane i for 0<=i<N is signed two's-complement INT8 in_data[8*i+:8]. All other input bits are ignored. Output lane j is signed two's-complement INT16 in out_data[16*j+:16], equal to sum_i (-1)^popcount(i AND j) * x_i. This is the unnormalized Sylvester ordering, with exact arithmetic and no rounding or saturation. All inactive output bits are zero. The maximum magnitude is 2048, which fits signed INT16. N=1 returns the accepted input sign-extended without a WORK cycle.

Evaluation compares a direct parity-matrix integer host oracle against source and Yosys-mapped Icarus simulations, including reset/backpressure, 257-cycle output stall, reset while output is blocked, acceptance latching, and changed inputs in flight. A separate iterative butterfly host oracle cross-checks all generated expected values. For B=(N/2)*log2(N), with B=0 at N=1, the per-request bound is 2*B+32 ready-high opportunities. Whole-run bound is count*(2*B+32)+1 after the final release. Frozen serial_butterfly performs one butterfly per work cycle, while stage_parallel performs one full stage per work cycle. The expected always-ready initiation intervals are B+2 and log2(N)+2 respectively; both equal 2 at N=1. Area is generic Yosys/ABC cell count; completion is workload cycles. No formal proof, routed physical PPA, or trained-RL claim is made.

All five N values must pass fixed gates: area<=4x serial, workload cycles<=serial, and saturated initiation interval<=B+6. Correct gate failure remains correct but unqualified. Only qualified cases receive balanced reward max(0,1-exp(mean(log(area_ratio*cycle_ratio))/2)). Gates and workloads are fixed before observing scored results.
