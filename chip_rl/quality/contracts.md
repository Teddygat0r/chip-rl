A[r,k] is signed byte in_data[8*(16*r+k)+:8]; B[k,c] is in_data[512+8*(4*k+c)+:8]. Only r<M,c<N,k<K are used; other input bits contain arbitrary junk. Exact signed dot products occupy out_data[24*(r*N+c)+:24], sign extended to 24 bits; unused output bits are zero. Accept input on valid&&ready, return exactly one ordered output at least one cycle later. Hold output valid and all data until accepted. No duplicate, unsolicited, unknown, dropped or post-reset stale work. Per accepted command deadline 256 cycles, epoch max_cycles; no timeouts count as success.
